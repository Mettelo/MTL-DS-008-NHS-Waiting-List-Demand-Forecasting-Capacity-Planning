## Working agreement
Teams should:
- create issues for substantive work;
- work in scoped branches;
- make meaningful commits;
- open pull requests;
- review each other's work;
- avoid one final bulk upload.

## Example branches
- `feature/rtt-data-pipeline`
- `analysis/time-series-eda`
- `model/sarima`
- `model/gradient-boosting`
- `evaluation/rolling-backtest`

## Example commits
- `feat: standardise monthly RTT extracts`
- `analysis: add seasonal diagnostics`
- `model: implement seasonal naive baseline`
- `test: add rolling-origin evaluation`
- `docs: document capacity planning assumptions`
