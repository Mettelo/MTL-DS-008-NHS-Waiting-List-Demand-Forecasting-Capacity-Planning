# 06 — Capacity Planning Interpretation

Translate the final forecast into an operationally useful view.

Include:
- current observed level;
- next 3–6 month forecast;
- forecast change;
- uncertainty/range;
- planning implication;
- clearly labelled scenario assumptions.

If converting waiting-list volume into capacity requirements, document every assumption.

Do not present illustrative capacity scenarios as official NHS staffing requirements.
