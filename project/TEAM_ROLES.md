# Suggested Team Roles

Recommended team size: **3–5 members**.

## Data Preparation Engineer / Scientist
Owns:
- monthly data acquisition;
- schema standardisation;
- target construction;
- quality checks.

## Forecasting Data Scientist
Owns:
- baseline;
- statistical forecasting;
- model assumptions;
- forecast generation.

## Machine Learning Data Scientist
Owns:
- lag/time features where used;
- ML candidate model;
- leakage prevention;
- comparative modelling.

## Model Evaluation & Validation Lead
Owns:
- backtesting design;
- error metrics;
- model comparison;
- uncertainty;
- robustness checks.

## Data Product / Technical Lead
May be combined with another role.

Owns:
- business framing;
- capacity interpretation;
- integration;
- reproducibility;
- documentation;
- final QA.

Every member must make substantive technical contributions.
