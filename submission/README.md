# Submission & Team Repository Guidance

This folder defines how teams must prepare and submit delivery work for **MTL-DS-008**.

## Required documents

- `TEAM_REPOSITORY_STANDARD.md` — mandatory repository and Mettelo access requirements
- `SUBMISSION_GUIDE.md` — step-by-step submission process
- `FINAL_SUBMISSION.md` — final submission record

## Core rule

Every delivery repository must be accessible to the **Mettelo GitHub organisation** for review, verification and quality assurance.

A submission is not complete until Mettelo organisation access has been verified.
